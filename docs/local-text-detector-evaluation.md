# تقييم كاشف نصوص محلي للمانهوا

استُكشف مشروع `dmMaze/comic-text-detector` ومشروع `zyddnys/manga-image-translator` كمصادر تقنية فقط. الأول يصف كاشف نص/كتل مدرّبًا على صور أنمي وكوميكس ويعيد صناديق نص وخطوطًا ومعلومات تقسيم، بينما يوفّر المشروع الثاني بنية ترجمة مانغا تتضمن مسارًا للكشف. هذا مسار واعد لاستبدال الاعتماد على مزود Qwen الذي تجاوز مهلة 15 ثانية مرارًا في عينة الفصل.

لم يُنزَّل أو يُشغّل أي نموذج خارجي بعد. قبل الدمج يجب عزل واجهة كشف محلية صغيرة داخل خدمة الاستدلال، والتحقق منها على صفحات الفصل المحتفَظ بها، ثم قبول المناطق فقط عندما يثبت أنها داخل فقاعة أو صندوق حوار. لا تُستخدم مخرجات كاشف النص وحدها لتبييض الرسم.
