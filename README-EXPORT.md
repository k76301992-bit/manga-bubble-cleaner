# Manga Bubble Cleaner — النسخة المستقلة

هذه الحزمة تفصل التطبيق والخادم عن أي خدمة تخزين مدمجة. يعالج تطبيق Expo الصورة من ملفات الجهاز أو من رابط، ويرسل بايتات الصورة إلى خادمك عبر `POST /api/v1/clean`. يبقى **الأصل والناتج** على جهاز المستخدم؛ الخادم يعيد PNG مباشرةً في الاستجابة ولا يكتب الصورة أو النتيجة إلى القرص أو تخزين كائني أو MongoDB.

| المكوّن | المسؤولية | ما لا يحتفظ به |
| --- | --- | --- |
| تطبيق Expo | اختيار الأصل، حفظ الأصل والنتيجة محليًا، المعاينة، المشاركة والتصدير | مفتاح Qwen أو أي مفتاح خادم |
| خادم Express + Sharp | كشف صناديق نص الحوار عبر Qwen، إنشاء القناع، الترميم في الذاكرة، إعادة PNG | ملفات الأصل/الناتج أو روابطها |
| MongoDB (اختياري) | حالة المهمة، التقدم، الأبعاد، رسالة الخطأ، وتاريخ انتهاء 7 أيام | البايتات، base64، الأصل، النتيجة |

> عند إعادة تشغيل الخادم، تضيع أي بايتات معالجة كانت في RAM. يعيد سجل MongoDB الحالة `requires-reupload`، حتى للمهمة التي كانت مكتملة، لأن النتيجة ليست محفوظة على الخادم. تحتفظ نسخة جهاز المستخدم بالنتيجة التي استلمها بالفعل.

## تشغيل الخادم

أنشئ ملف `.env` على الخادم وضع فيه `EXTERNAL_OPENAI_API_KEY` على **الخادم فقط**. القيم المطلوبة والاختيارية موضحة في [إعدادات البيئة](DEPLOYMENT-ENV.md). لا ترفع هذا الملف إلى Git ولا تضف المفتاح إلى متغيرات `EXPO_PUBLIC_*`.

```bash
pnpm install
pnpm build
pnpm start
```

للتطوير المحلي شغّل:

```bash
pnpm dev:server
```

اختبار الصحة هو `GET /api/health`. تقبل `POST /api/v1/clean` جسمًا خامًا من PNG أو JPG أو WebP بحد 20 ميغابايت و20 مليون بكسل. الاستجابة الناجحة `image/png` وتضم رأس `X-Cleaner-Job-Id`. يعالج الخادم **طلب تنظيف واحدًا فقط في الوقت نفسه**؛ الطلب الموازي يحصل على `429 server-busy` بدل استهلاك الذاكرة بصورة غير منضبطة.

يمكن تعيين `SERVICE_API_KEY` عندما يكون المتصل بوت Discord أو خادمًا موثوقًا؛ عندها أرسل `Authorization: Bearer <key>`. لا يصلح هذا النوع من المفاتيح داخل IPA لأنه يصبح قابلًا للاستخراج. تطبيق عام للفريق يحتاج مصادقة مستخدم أو بوابة API مناسبة قبل تعريض الخادم للإنترنت.

## بناء IPA مستقل

قبل بناء التطبيق، عيّن `EXPO_PUBLIC_API_BASE_URL` إلى عنوان HTTPS العام لخادمك. لا توجد قيمة افتراضية صالحة للإصدار المنشور؛ لذلك يفشل التطبيق برسالة واضحة بدل إعادة توجيه صورة إلى بيئة تطوير. يبقى حفظ المشاريع والأصول والنتائج محليًا على الجهاز عبر Expo FileSystem.

غيّر `rawBundleId` في `app.config.ts` إلى معرف الحزمة الذي تملكه قبل النشر في المتاجر، مثل `com.yourstudio.mangabubblecleaner`. أيقونات التطبيق موجودة محليًا في `assets/images` ولا تحتاج رابطًا خارجيًا.

## التحقق قبل النشر

```bash
pnpm check
pnpm test
pnpm lint
pnpm build
```

يتحقق اختبار MongoDB من أن وثيقة المهمة لا تحتوي الأصل أو النتيجة أو `base64`. لا تشغّل خادمًا عامًا بلا طبقة تحكم بالوصول أو حد استخدام مناسب؛ قفل الطلب الواحد يحمي الذاكرة لكنه ليس بديلًا لمصادقة المستخدمين أو حدود الاستعمال.
